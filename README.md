# Login Page Demos

Static HTML replicas of login pages for Apple, Google, Facebook, and X (Twitter). Built for practice and educational purposes.

|------|------|
| `accediconapple` | Apple login |
| `accedicongoogle` | Google login |
| `accediconfacebook` | Facebook login |
| `accediconx` | X (Twitter) login |

These are front-end-only UI clones — no backend, no data collection. Created as a CSS/HTML layout exercise.
